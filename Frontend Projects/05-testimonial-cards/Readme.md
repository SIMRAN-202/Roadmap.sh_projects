# Testimonial Cards

### Project URL:

[Click on the link](https://roadmap.sh/projects/testimonial-cards)

### Goal
The goal of this project is to create visually appealing testimonial cards using HTML and CSS. These cards will display customer feedback or reviews to build trust and credibility on a website.
Through this project, you'll learn about CSS positioning, layout techniques, box model, and responsive design.

### Requirements
- [x] Create multiple testimonial cards using HTML and CSS.
- [x] Each card should include a user image, name, designation, and testimonial text.
- [x] Use flexbox or CSS grid for proper alignment and spacing.
- [x] Add box shadows, borders, and rounded corners for styling.
- [x] Make the layout responsive for different screen sizes.
- [x] Use consistent fonts, colors, and padding for a clean appearance.
