# Tooltip UI

### Project URL:

[Click on the link](https://roadmap.sh/projects/tooltip-ui)

### Goal
The goal of this project is to create a tooltip for navigation items using only HTML and CSS.
When a user hovers over a navigation item, a small pop-up box (tooltip) should appear above it, displaying additional information.

### Requirements
- [x] Use only HTML and CSS, no JavaScript.
- [x] Create a navigation bar with multiple items (e.g., Home, About, Services, Contact).
- [x] Display a tooltip above each navigation item when hovered.
- [x] Include smooth animation for tooltip appearance (fade-in, slide-in, or scale-in).
- [x] Ensure the tooltip has a clear label or description text.
