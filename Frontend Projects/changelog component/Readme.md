### Project URL:

[Click on the link](https://roadmap.sh/projects/changelog-component)

### Goal
The goal of this project is to teach you about positioning and layout in CSS. You will create a simple HTML structure and use CSS to style it into a visually appealing and responsive changelog component. Given below is a rough mockup of the changelog component you need to create.

### Requirements
- [x] Use HTML to structure the changelog with dates and descriptions.
- [x] Style the component using CSS, including spacing, alignment, and colors.
- [x] Include a vertical timeline or connecting elements to represent updates.
- [x] Make the component responsive for different screen sizes.
- [x] Optionally, add hover effects or buttons for enhanced interactivity.
