# Task tracker

### Project Link
[Click on the link](https://roadmap.sh/projects/task-tracker)

### Goal  
Build a simple **CLI app** to add, update, delete, and track tasks directly from the terminal.  
It helps manage what’s pending, in progress, or done — all stored locally in a **JSON file**.  
This project strengthens your skills in **file handling**, **CLI inputs**, and **JSON data management**.  

---

### Requirements  
- Runs entirely from the **command line** using positional arguments.  
- Stores tasks in a **JSON file** (auto-created if missing).  
- Supports adding, updating, deleting, and marking tasks by status.  
- Allows listing all tasks or filtering by `todo`, `in-progress`, or `done`.  
- Must use **native modules only** and handle errors gracefully.
